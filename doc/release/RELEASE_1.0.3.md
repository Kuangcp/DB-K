# db-k v1.0.3 发布公告

> **Release 标题建议**：`db-k v1.0.3`
>
> 本次从 `v1.0.2` 起累计 75 个提交、142 个文件（+22091 / −4780）。
> 重点：**中英双语**、**工作区（控制台虚拟分组）**、**命名主题系统**、
> **外部 SQL 文件控制台**、**结果区矩形多选与复制**、**全局界面缩放**，
> 以及一批编辑器交互与稳定性修复。

1.0.3 主要把「日常使用的顺手程度」补齐：界面与文案中英双语；控制台可按工作区分组；
主题可自定义并持久化；外部 `.sql` 文件能像普通控制台一样打开、编辑、双向同步；
结果区支持框选复制，分享 EXPLAIN 之类的多行文本不再逐格复制。

---

## ✨ 新特性

### 国际化（i18n）—— 中 / English
- 全部用户可见文案走统一 key 注册表，中英双语即时切换、语言偏好持久化。
- 非 UI 层（`jdbc`/`tree`/`db`/`engine` 等）统一 `I18n.t(...)`，派生/缓存模型只存 key，切换语言不残留旧译文。

### 工作区（控制台虚拟分组）
- 控制台可按「工作区」分组：新建 / 切换 / 重命名 / 删除；标签条右侧下拉快速切换。
- 工作区成员、激活记忆、MRU 持久化；`consoles.closed` 退役（关闭 = 移出当前工作区，行与正文仍保留）。
- 数据源右键「打开控制台」级联按工作区找回已关闭控制台。

### 命名主题系统
- 内置 **5 套主题**：`Dark`、`Light`、`Monokai`、`Dracula`、`Sublime`，只读不可改。
- 改内置配色 → 引导「另存为新主题」，自定义主题可改精选 11 项配色（背景/表面/前景/主色 + 编辑器 + 语法）。
- 顶栏 Moon/Sun 切换升级为**主题下拉** + 「管理主题…」对话框；`themes.json` 持久化。

### 外部 SQL 文件控制台
- 打开 / 拖入本地 `.sql` 文件，作为普通控制台使用（数据源关联、执行、光标/撤销记忆）。
- 磁盘**双向同步**：编辑器写回文件；外部改动经文件监听（父目录监听 + 防抖 + mtime 兜底）干净重载、脏时冲突、缺文件标记。
- 冲突 / 缺失横幅：重载 / 保留我的 / 重建 / 另存为；退出保护不静默丢未保存改动。

### 结果区增强
- **矩形多选**：Shift+点击 / Shift+方向键扩展、Ctrl+A 全选、方向键单选移动。
- **复制选区 → CSV / TSV（含表头）**；Ctrl+C 多选 = 无表头 TSV，单选 = 单元格值。
- 工具栏「复制全部（TSV，含表头）」+ 右键「复制本行 → TSV（含表头）」，EXPLAIN 等多行结果一键复制分享。
- pin 结果、单语句结果顶栏状态点、列宽按 CJK 双宽估算（长列名不再被省略）。

### 全局界面缩放（UI Scale）
- 设置 → 通用设置 →「界面缩放」滑块（100%~200%，步进 5%），**实时预览**、取消回退、保存落盘。
- 覆盖主窗口与全部对话框（字体 / 图标 / 边框等比放大），默认 100% 与旧行为完全一致。

### 编辑器增强
- `Ctrl+Tab` / `Ctrl+Shift+Tab` 按 MRU 切换控制台；多光标列编辑（`Alt+Shift+↑↓`）；`Ctrl+Y` 复制当前行。
- `Ctrl+Enter` 无选区时自动执行光标处的**只读查询**。
- gutter 行状态标记：每条语句执行结果逐条点亮（成功绿 / 失败红 / 执行中黄 / 跳过灰）。

### UI / 其它
- 三栏布局记忆（左树宽 / 编辑-结果分隔比例）+ `Ctrl+B` 显隐左侧树。
- 左树拖拽（数据源 / 文件夹移动排序、文件夹嵌套）；单击树节点只选中、双击连接。
- 主题 / 工作区下拉紧凑化；无边框窗口缩放热区缩小（结果区滚动条可正常抓取）。
- 连接编辑允许数据库名留空（SQLite 文件路径仍必填）；应用图标改白底三段色 `K`。

## 🐛 修复
- 编辑器**双击选词 / 拖选被打断**：`outputTransformation` 每敲键重建导致 Compose 重置指针手势；
  改为稳定变换器 + 动态值经 snapshot state 读取（刚编辑完双击无反应、再双击才选中的问题）。
- 拖右侧滚动条到底 / 回顶会**误触发自动滚动选字**（滚动条按下被当成文本拖选）。
- 主题「另存为新主题」不再把内置主题混进自定义列表导致下拉重复显示。
- PG「类型」组排除表 / 视图自动生成的行类型；新建 / 重命名弹窗自动聚焦输入框。
- 拖入文件按 URI 解析；退出「放弃外部文件内容」后继续走未提交结果修改确认。

## ⚠️ 行为变更 / 注意
- 顶栏明暗切换按钮改为**主题下拉**（含管理主题入口）。
- 控制台「关闭」语义交由工作区：关闭 = 从当前工作区移除，行与 `.sql` 正文保留，可从数据源右键「打开控制台」找回。
- 结果区新增「复制全部 / 复制选区 / 复制本行 TSV」；「复制本行 CSV / 本行 TSV」对**截断行 / 转置视图**仍不提供（避免复制不完整内容）。

## 📦 安装与升级

- **AppImage**（单文件）：`db-k-1.0.3-x86_64.AppImage`，需 glibc ≥ 2.28（Debian 10+ / Ubuntu 20.04+ / RHEL 8+）。
- **Deb**：`gradle packageDeb` → `db-k_1.0.3_*.deb`。
- **MSI**（仅 Windows 构建）：`gradle packageMsi` → `db-k-1.0.3.msi`，升级 UUID 固定，可直接覆盖升级。
- **免安装目录**：`gradle createDistributable`。

升级无需迁移操作：本地数据（连接 / 控制台 / 历史 / 主题 / 工作区）自动兼容。
新增 `workspaces` + `workspace_consoles` 表（迁移 v10）、`consoles.closed` 退役（v11）、
`consoles` 外部文件列（v12，`external` + `file_path`），旧数据自动补齐。
新增配置：`themes.json`、`app.properties` 的 `ui.scale`（默认 100%）。
